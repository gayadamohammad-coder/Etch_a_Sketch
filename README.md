# Etch-a-Sketch

This is my solution for the Etch-a-Sketch project from The Odin Project.

Project link:
https://www.theodinproject.com/lessons/foundations-etch-a-sketch

## Features

- 16x16 default grid
- Change the grid size (up to 100x100)
- Draw by hovering over the cells
- Random RGB drawing mode
- Black drawing mode
- Eraser mode
- Progressive darkening effect

## Built With

- HTML
- CSS
- JavaScript

## What I Learned

While building this project I practiced:

- DOM manipulation
- Event listeners
- Creating elements with JavaScript
- Working with loops
- Changing CSS with JavaScript
- Building interactive web pages

This project helped me get more comfortable with JavaScript and DOM manipulation.
